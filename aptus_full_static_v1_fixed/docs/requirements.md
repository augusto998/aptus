# Requisitos

## Funcionais

RF01 — Permitir login separado para usuário e nutricionista.
RF02 — Persistir sessão localmente no navegador.
RF03 — Exibir perfil e indicadores do usuário.
RF04 — Permitir editar perfil do usuário.
RF05 — Exibir feed vertical de conteúdo.
RF06 — Permitir publicar conteúdo.
RF07 — Permitir curtir publicações.
RF08 — Permitir comentar publicações.
RF09 — Exibir receitas e detalhes de preparo.
RF10 — Listar nutricionistas.
RF11 — Permitir iniciar conversas com nutricionistas.
RF12 — Exibir mensagens em conversas.
RF13 — Exibir painel do nutricionista.
RF14 — Exibir consultas e pacientes no painel profissional.

## Não funcionais

RNF01 — Interface responsiva para desktop e celular.
RNF02 — Navegação sem dependências de servidor para a demo.
RNF03 — Persistência local usando IndexedDB.
RNF04 — Dados de demonstração disponíveis na primeira execução.
RNF05 — Estrutura organizada em HTML, CSS, JavaScript e documentação de banco.
RNF06 — Compatível com hospedagem estática como GitHub Pages.
