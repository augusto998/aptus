# Histórias de usuário

## Usuário

Como usuário, quero entrar em uma área própria para acompanhar meus hábitos.

Como usuário, quero editar meu perfil para registrar objetivo, bio e localização.

Como usuário, quero visualizar um feed de vídeos/cartões para descobrir receitas e curiosidades.

Como usuário, quero curtir e comentar publicações para interagir com a comunidade.

Como usuário, quero consultar receitas completas para conseguir reproduzir preparos.

Como usuário, quero encontrar nutricionistas para buscar orientação profissional.

Como usuário, quero enviar mensagens para um nutricionista para acompanhar minha rotina.

## Nutricionista

Como nutricionista, quero entrar em uma área profissional separada.

Como nutricionista, quero visualizar minhas consultas e pacientes.

Como nutricionista, quero publicar conteúdo educativo.

Como nutricionista, quero responder mensagens de pacientes.
