# Requisitos Funcionais — APTUS

- **RF01:** O sistema deve permitir cadastro de clientes.
- **RF02:** O sistema deve possuir login separado para cliente e nutricionista.
- **RF03:** O sistema deve encerrar sessão do usuário.
- **RF04:** O sistema deve armazenar senhas com hash.
- **RF05:** O cliente deve visualizar e editar seu perfil.
- **RF06:** O cliente deve visualizar estatísticas básicas do perfil.
- **RF07:** O sistema deve permitir criar publicações.
- **RF08:** Publicações devem aceitar texto e mídia opcional.
- **RF09:** O sistema deve exibir um feed social com cartões verticais.
- **RF10:** O cliente deve curtir/descurtir publicações.
- **RF11:** O cliente deve comentar publicações.
- **RF12:** O cliente deve seguir/deixar de seguir perfis.
- **RF13:** O sistema deve permitir associar uma receita a uma publicação própria.
- **RF14:** O sistema deve exibir nutricionistas disponíveis.
- **RF15:** O cliente deve solicitar acompanhamento de um nutricionista.
- **RF16:** O sistema deve permitir mensagens diretas entre cliente e nutricionista.
- **RF17:** O nutricionista deve visualizar solicitações recebidas.
- **RF18:** O nutricionista deve atualizar o status de uma consulta.
- **RF19:** O nutricionista deve inserir data/hora de agendamento.
- **RF20:** O sistema deve restringir o painel profissional a nutricionistas.
- **RF21:** O sistema deve persistir as funcionalidades principais no PostgreSQL.
- **RF22:** O sistema deve utilizar exatamente 10 tabelas funcionais no PostgreSQL.
