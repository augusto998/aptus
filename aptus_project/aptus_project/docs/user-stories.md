# User Stories — APTUS

## Cliente/usuário

### US01 — Cadastro
**Como** visitante, **quero** criar uma conta com nome, usuário, e-mail e senha, **para** acessar a plataforma.

**Critérios:** dados obrigatórios validados; usuário/e-mail únicos; senha armazenada com hash.

### US02 — Login
**Como** usuário, **quero** entrar em uma área de login própria, **para** acessar meu perfil.

### US03 — Perfil
**Como** usuário, **quero** editar meu nome, bio e objetivo, **para** personalizar minha experiência.

### US04 — Publicação
**Como** usuário, **quero** publicar texto e mídia, **para** compartilhar aprendizados, curiosidades e receitas.

### US05 — Feed/Reels
**Como** usuário, **quero** visualizar publicações em formato de feed com cards verticais, **para** descobrir conteúdo rapidamente.

### US06 — Interação
**Como** usuário, **quero** curtir, comentar e seguir perfis, **para** interagir com a comunidade.

### US07 — Receita
**Como** usuário, **quero** associar uma receita a uma publicação, **para** compartilhar preparo, ingredientes e tempo.

### US08 — Nutricionista
**Como** usuário, **quero** visualizar nutricionistas e enviar mensagem, **para** buscar acompanhamento profissional.

### US09 — Solicitação
**Como** usuário, **quero** solicitar uma consulta, **para** iniciar um acompanhamento.

## Nutricionista

### US10 — Login profissional
**Como** nutricionista, **quero** uma área de login separada, **para** manter a experiência profissional distinta.

### US11 — Perfil profissional
**Como** nutricionista, **quero** editar minha especialidade e apresentação, **para** mostrar informações profissionais.

### US12 — Gestão de consultas
**Como** nutricionista, **quero** visualizar e atualizar solicitações, **para** organizar atendimentos.

### US13 — Mensagens
**Como** nutricionista, **quero** responder mensagens, **para** manter contato com clientes.
